Runs on your computer with Python 3.9+. Open Safari on the iPhone; no iOS app installation needed.

Built for the files that matter

Keep original quality

Transfers file bytes as provided by the browser. WarpCoil does not transcode or recompress your video.

Pick up where you left off

Chunked transfers support resuming interrupted uploads when transfer metadata matches.

Direct local connection

Your files stay on your network and are saved to a folder on your computer. No WarpCoil cloud service.

From iPhone to computer in minutes

  1. Download the source ZIP from the releases page and extract it on Windows or Ubuntu.
  2. Start WarpCoil: on Windows, double-click start_windows.bat; on Ubuntu, run bash start_ubuntu.sh.
  3. Connect: join the same trusted local network on iPhone, open the local address displayed by the computer in Safari, and enter the on-screen PIN.
  4. Select files: choose a video or another file in Safari and follow transfer progress. Files are saved under your computer's Videos/WarpCoil directory by default.

Need Python? Download Python 3. No extra Python packages required.

Private by design, but mind the network

Beta security noticeWarpCoil v1.3.0 uses unencrypted HTTP. Pairing uses a PIN, but traffic and authentication can potentially be observed by others with access to the network. Use only on trusted home or office networks. Never expose port 8765 to the internet or use public Wi-Fi.

Read the security policy and report issues through the GitHub issue tracker (avoid publishing sensitive details).
