# WarpCoil 1.3.2 — English user interface

All app UI, diagnostics, and command-line strings are now in English. The transfer engine, pairing tokens, browser storage keys and resumable metadata remain compatible with v1.3.1. The Python entry point stays `localdrop.py` and the default folder stays `~/Videos/LocalDrop` to avoid breaking existing installations.

This software uses unencrypted HTTP and must be run only on a trusted local network.
